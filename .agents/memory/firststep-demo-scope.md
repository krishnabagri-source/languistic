---
name: FirstStep demo scope
description: Product boundary for FirstStep's initial communication-support prototype.
---

Keep the initial FirstStep analysis client-side, deterministic, and clearly labeled as illustrative. Do not transmit or persist message content, imply real AI understanding, or add a backend/API key unless a real backend is explicitly implemented and verified.

**Why:** The product brief requires a self-contained frontend prototype and prohibits claims that a backend or real AI integration exists before implementation and testing.

**How to apply:** Preserve the local `AnalysisService` boundary; any future remote analysis should be a separate, explicitly implemented server-side integration with appropriate privacy safeguards.
